# Meme Library · คลังมีม
Mockup meme library (personal use). Live: https://piyaster11.github.io/meme-library/

## Add a meme
1. Put the image in `img/` (jpg/webp, max ~800px).
2. Add an entry to `data/memes.json`:
```json
{"id":"my-meme","name":"My Meme","name_th":"มีมของฉัน","tags":["funny","ตลก"],"occasions":["work","friday"],"rank":81,"img":"img/my-meme.jpg","source":"where it came from"}
```
Occasion keys: work, monday, friday, payday, broke, birthday, thanks, sorry, love, food, sad, happy, shocked, agree, disagree, songkran, newyear, loykrathong.
3. Commit & push to `gh-pages`.

Credits: templates via Imgflip popular templates; images belong to their owners; tags are our own labels.

## Add a reply meme (square 1:1, original wording)
Reply memes keep each meme's ORIGINAL English text (no translation on the image). Generated by `tools/make_reply_memes.py` (Pillow + `tools/fonts/Anton-Regular.ttf`, Impact-style white text with black outline).
1. Put the template in `img/` (or use an existing one).
2. Add a line to `REPLIES`: `(id, template, crop_or_None, top_text, bottom_text, [occasions], 'search keywords incl. Thai')`. Leave text empty if the template already has its own text. crop = fractions `(x0,y0,x1,y1)`.
3. Run `python3 tools/make_reply_memes.py` → 1080x1080 jpgs in `img/reply/` and entries in `data/memes.json` (`type:"reply"`, `ratio:"1:1"`, `caption_original`). Thai keywords go in tags only (for search), never on the image.
4. Commit & push to `gh-pages`.
